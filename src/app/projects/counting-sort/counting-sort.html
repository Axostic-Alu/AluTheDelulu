Sort withoutcomparing.

Counting sort puts small whole numbers in order in linear time. Scroll to watch it work.

Counting sort never compares two values. It counts how often each value appears, then uses running totals to drop every item straight into its final slot.

  • No comparisons
  • Whole numbers 0 to k
  • Stable

Think of buckets

Each possible value gets its own bucket. Every number that arrives drops into its bucket, and the height of each pile is that value's count.

The taller the pile, the more times that value appeared: three 3s means count[3] = 3.

Why it is fast

It just counts and places values, so no comparisons are needed.

O(n + k)time
O(n + k)extra space
Stableequal values keep their order

Schematic, with k small compared to n.

Why place from the right?

Reading right to left fills the last slots first, so equal values keep their original order.

When to use it

Use it when

  • Values are small whole numbers, like exam scores from 0 to 100
  • The range k is small compared to the number of items
  • You need a stable sort, or a step inside radix sort

Avoid it when

  • The range is huge, like 1 to 1 billion
  • Values are decimals or strings
  • Memory for the count array is tight

The algorithm

  1. Find the biggest value, k.
  2. Make a tally list with a spot for every value from 0 to k.
  3. Go through the input and add 1 to the tally of each value.
  4. Add the tallies from left to right, so each one shows where its value ends.
  5. Go through the input from the right and put each value in its slot.
